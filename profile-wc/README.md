## What’s new vs 10×

Same information architecture and S0–S9 scenarios — elevated craft on **every** screen:

| Area | Upgrade |
|------|---------|
| Root | Ready chip, photo avatar, status **pills** (no competing trailing counts), no mid-word truncation, OMRON brand blue |
| You | Progress bar (n of 3), “Add …” CTA to first missing field, dual BP goal fields, height unit toggle, product copy only |
| Devices | Empty state illustration, device **hero** art + Transfer now, pairing steps 1–2–3 |
| Account | Clear cloud / sign-in / danger hierarchy; polished sheets |
| Settings / Help | FAQ cards, video row, Premium plan card, About mark |
| System | Screen transitions, toast with check, 8pt grid, larger type on fields |
