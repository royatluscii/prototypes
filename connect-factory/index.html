Quality is whether this loop holds. Gates on pull requests help. They are not a substitute for that number.

What changed

Every proposed change now hits a gate: tests, coding rules, crash and database checks, a merge queue. iOS has 49 written standards audited on the pull request. Merge to main and a build goes to TestFlight the same day. Device tests run overnight. Android has the same idea — quality gates, release trains, crash reporting scoped to production.

People do not remember rules. The gate rejects the bad part. Old code still exists. New work is held to the bar when it is touched.
